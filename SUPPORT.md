# Support

- Use [GitHub Discussions](https://github.com/alitycs/alitycs-sdk-jvm/discussions) for integration
  questions and usage help.
- Use [GitHub Issues](https://github.com/alitycs/alitycs-sdk-jvm/issues) for reproducible SDK bugs.
- Use [private vulnerability reporting](SECURITY.md) for security concerns.

Include the SDK version, JDK and Kotlin versions, relevant configuration with secrets removed,
expected behavior, actual behavior, and a minimal reproduction. General Alitycs documentation is at
[docs.alitycs.com](https://docs.alitycs.com).
